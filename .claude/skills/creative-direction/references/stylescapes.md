# Stylescapes — Building and Presenting the Three Concepts

> **Worked exemplar:** [../examples/magister-stylescapes.html](../examples/magister-stylescapes.html) — a full three-concept interactive set with `1·2·3` nav and a side-by-side compare view.

For **Revolution** (and serious Evolution) engagements: the discovery from `brand-strategy` becomes three distinct creative concepts, each expressed as a stylescape.

## What a stylescape is (and isn't)

A stylescape is a wide, composed board that shows a concept as **real intended assets** — the actual color palette, the actual typeface pairing set in real headlines, the motif in use, sample UI/hero fragments, photography treatment, iconography — arranged as one continuous visual statement.

- **Not a mood board.** A mood board collects *other people's* work; a stylescape shows *this brand's* intended language.
- **Not a CSS-block comp.** A stylescape is a *rendered, art-directed surface*: treated imagery, real texture, depth, overlap, scale contrast, bleed.
- **Expressive and free.** At this stage the concept is not yet constrained by buildability.

## The anatomy — every element, every board

1. **A hero line, set for real.** Never lorem in the hero.
2. **Treated imagery or a committed illustration style.**
3. **A type specimen — named, by role.** Name the actual typefaces.
4. **A color system with roles.** Swatch blocks with named roles, hex values, and at least one ramp.
5. **An ownable motif or texture, derived from the concept.** A dot-grid on flat canvas is the *default*, not an ownable motif.
6. **A custom icon set** in the concept's voice.
7. **Applied mockups.** Non-negotiable: this is how you prove the direction survives application.
8. **The product's real work, shown through the muse.** Show what the product *does*, rendered *in* the muse's abstraction.
9. **Composition with depth.** Collage layering, overlap, rotation, full-bleed imagery, dramatic scale contrast.

## The three concepts

- Each is a **genuinely different answer to the same Emotional Target** — different muses, different color story, different type pairing, different attitude.
- Anchor each in 1–2 of the muses from `brand-strategy`, and name the connection.
- **Each concept owns its OWN muse — never template one concept's signature across the others.**
- **Break the template — each concept gets its own *composition*, not the same grid recolored.**
- **Cascade one signature treatment through the whole board.**
- **One motif *system* per board — don't stack line-motifs.**
- **Build order: nail one board to the finished bar first, then cascade the attention one at a time.**
- **A set is only as strong as its weakest board.**

## Composing a stylescape — a coalesced board, not a webpage

**Think bento grid, then break it.** Lay the elements as tiles of *different sizes*, then deliberately **overlap the tile boundaries**. Tiles should *talk to each other*, not sit in isolation.

- **Depth is mandatory:** layering, overlap, rotation, full-bleed imagery, dramatic scale contrast.
- **Read order still holds** underneath the collage.
- Use **real copy** from the brand.

## The board is a live, interactive canvas

- **A slow sweeping background element** gives the whole composition dynamism.
- **Ambient loops and glow** on the signature element and accents.
- **Hover reveals and shifts.**
- **Tabbed / clickable exploration.**
- **Make the signature element genuinely operable *and stateful*, not a picture of one.**
- **Color is an interactive switchboard** — clicking a swatch reveals that color's ramp.
- **Run the concept's texture as a living background motif.**

## Presenting the set

- **A floating side nav** — the three concepts stacked, each showing its number, name, and a one-line descriptor.
- **Offer a compare view** — all three side by side.
- **Build all three to the same fidelity.**

## The self-audit

- **Run a plain design-principles pass first, per board.**
- **Run ai-slop.md against your own output and *list what it finds*.**
- **Score against the confirmed competitor set.**
- **The applied mockup must pass too.**

## Synthesis vs. averaging

**Averaging** produces a fourth direction that means nothing. **Synthesis** is legitimate when the combined direction has its *own* single story that is stronger than either parent.

## After the pick

- Develop the chosen concept into the full element spec.
- Run the adversarial self-audit one more time.
- Record the system in `.agents/brand.md`, then proceed to `logo-design`.
