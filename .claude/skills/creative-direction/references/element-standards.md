# Element Standards — the Bar per Asset Class

The per-element detail behind `creative-direction`. Each element ends with the same two tests: *does it trace to a muse or the emotional target?* and *would it score 4–5 in the audit against the confirmed competitor set?*

## Color

- **Roles first, values second:** background, text primary, text secondary, **action/CTA**, support.
- **Five stops per color** (base + 2 shades + 2 tints).
- **Verify ownership:** lay the palette against every confirmed competitor.
- **Demonstrate the palette *coordinating*.**
- WCAG AA pairs documented for every text/background combination.

## Typography

- **Contrast, not competition:** the display face and body face should have unmistakably different jobs.
- **System cohesion:** prefer a superfamily's own cut or a deliberate companion.
- **Restrictions are part of the spec:** allowed weights, style rules, prohibited faces.
- **Weight discipline — default regular-to-semibold; reserve bold.**
- **Licensing checkpoint (before approval):** foundry, license type, budget, character coverage.
- **Evoke the muse, don't costume it.**
- **A different body face per concept.**
- **Neutral beats try-hard; the system carries the distinction. Banned faces: Space Grotesk, Fraunces** and their cohort.

## Composition & Layout

- Define the grid, container widths, spacing rhythm, and density.
- **Section variety is a requirement.**
- Decide how the eye is directed.

## Pattern & Texture

- The most brand-coherent motif source is the **mark's own geometry**.
- The motif must work **without the logo and without the brand color**.
- Check collisions with competitor motifs.
- Define usage: where it appears and where it must not.

## Iconography

- One source of truth with documented grid, stroke weight, corner treatment, fill policy.
- Plan the **tiers**: utility now; storytelling and illustration as the brand matures.
- One icon = one concept.

## Illustration & Product Abstraction

- **Branded abstractions over raw screenshots.**
- If illustration exists, define its style tightly enough that two illustrators would converge.
- "No illustration" is a valid, *explicit* decision.

## Photography

- Define subjects, treatment/grade, composition conventions, and sourcing.
- If photography isn't part of the brand, say so explicitly.

## Motion (directional)

- Name the brand's motion character in one line.
- Intent hierarchy: state-change/hover > page-load > scroll > ambient loops.
- **Motion can *communicate the concept*, not just decorate it.**
- Full motion specs live with the application skills; here you set the *feel*.
