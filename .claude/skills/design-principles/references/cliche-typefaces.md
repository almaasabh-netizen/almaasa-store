# Cliché Typefaces — the Catalog and the Law Behind It

The companion to [ai-slop.md](ai-slop.md)'s Type section.

## The wave law (read this before the list)

The most important finding: **the ban list decays**. The 2024–25 "escape Inter" advice recommended Fraunces, Instrument Serif, Geist, Clash Display, and Satoshi as the *cure* for default-font slop — and within one cycle, the same design community was posting "Slop fonts: Space Grotesk, Instrument Serif, Geist, Syne, Fraunces."

So the durable rule is not a list — it's a test:

> **A typeface is trite when it arrives without a decision.** If the face would appear anyway — because it's the template default, the model's statistical center, the current "designed-looking" fashion, or the literal costume for the muse — it is unchosen, and unchosen reads as slop regardless of the face's intrinsic quality.

Three failure modes, one law:
1. **The undecided default** — the face nobody picked.
2. **The try-hard wave face** — the face picked *to look designed*.
3. **The costume face** — the face picked because it literally matches the muse or category.

A face escapes the list only by being **the muse abstracted** or **a neutral chosen deliberately**.

## The catalog, by cohort

### 1. The AI / vibe-coding wave (the current tell — banned as defaults)
- **Space Grotesk** — the #1 tell
- **Fraunces** — the character-serif every generated "warm premium" brand lands on
- **Instrument Serif / Instrument Sans**
- **Syne**
- **Geist** — Vercel's system face
- Creator-template cohort: **DM Sans, Manrope, Plus Jakarta Sans, Outfit, Sora, Urbanist**

### 2. The Fontshare / "premium free" wave (the next slop in line)
- **Satoshi**, **Clash Display**, **General Sans**, **Cabinet Grotesk**, **Switzer**

### 3. The undecided defaults (legitimate ONLY when deliberate)
- **Inter, Roboto, Arial, Helvetica-as-reflex, Open Sans**, raw system stacks
- The nuance: a neutral face *chosen* — with motif, color, composition, and treatment carrying the distinction — beats a try-hard face every time.

### 4. The startup-blanding era (2015–2020)
- **Montserrat**, **Poppins**, **Lato**, **Raleway**, **Nunito**

### 5. The Canva / DIY era
- **Playfair Display**, **Bebas Neue**, **Lobster**, **Dancing Script / Great Vibes**

### 6. Costume faces (category literalism — the abstraction failure)
- **Trajan** — overused on epic/historical movie posters
- **Cinzel** — web-font Trajan; all-caps Roman for anything imperial/classical
- **Papyrus** — "ancient/exotic/natural" costume
- **Copperplate Gothic** — the law-firm / steakhouse / bank default
- **Blackletter for medieval, Lithos for Greek**
- **Chop-suey / "wonton" faces** for anything East-Asian — cliché *and* offensive

### 7. The classic amateur tells (permanent list)
- **Comic Sans**, **Papyrus**, **Impact**, **Brush Script**, **Curlz MT**, **Bradley Hand**, **Hobo**

## How to apply this

- **Cohorts 1–2 and 4–7: do not reach for these.**
- **Cohort 3 is conditional:** deliberate neutrality is a legitimate, often superior strategy.
- **Refresh the wave cohorts.** When auditing, ask: "would three other brands in this category plausibly ship this face this quarter?"
- **The audit question:** was this face *decided* — and can the decision be stated in one sentence that traces to the muse or the emotional target?
